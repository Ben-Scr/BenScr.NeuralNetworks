# Changelog

## 1.0.0

- Dense CPU networks with Linear, Sigmoid, Tanh and ReLU activations.
- Seeded initialization, shuffled mini-batch SGD and optional target-loss stopping.
- Analytic sample gradients and finite arithmetic checks.
- Validated version-one JSON persistence and copied input/parameter ownership.
- .NET 10 support, documented limits, package consumers and portable Source Link symbols.
